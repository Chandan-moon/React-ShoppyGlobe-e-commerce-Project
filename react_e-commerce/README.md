# React -- ShoppyGlobe E-commerce Application
Welcome to ShoppyGlobe! This application is a fully functional, dynamic React web application built using Vite , React Router for seamless navigation , Redux Toolkit for centralized state management , and customized with Vanilla CSS.  



Users can browse a wide array of products fetched dynamically from an API endpoint , search for specific titles using real-time filtering , view highly detailed product breakdowns , manage items inside an interactive shopping cart , and simulate checking out via a verified details form.  



# Features

Home Dashboard: --> Renders an elegant grid list layout of all marketplace products using optimization hooks and unique key mapping arrays. 



Dynamic Routing Filters: --> Leverages a modern, dynamic router architecture (createBrowserRouter) to fluidly link separate core pages.  



Interactive Dynamic Details: --> Pulls individual product profile parameters dynamically from route metrics upon mounting onto the UI view.  



Redux Controlled Shopping Cart: --> Manages additions, individual asset quantity modifications (ensuring counts never fall below 1), and complete item deletions via Redux slice selectors.  



Comprehensive Form Verification: --> Captures user information on a dummy shipping form, prints itemized total calculation reviews, flushes the cart state on submission, and auto-redirects home.  



Performance Optimization: --> Features clean chunk code-splitting using React.lazy and <Suspense> boundaries coupled with native image lazy loading.  




# Prerequisites

-- Before launching the workspace locally, ensure you have the following installed on your machine:

# Node.js (v16.x or higher recommended)

# npm (Node Package Manager)



# How to Run the Application
Follow these simple steps to get your local server running:

1. Extract and Navigate to the Directory
Unzip the project file or clone your repository, open your terminal application, and move into the project root:

# Terminal:  cd shoppyglobe-app


2. Install Project Dependencies
Run the installation command to download the required node modules package configurations (including React Router and Redux Toolkit):

# Terminal: npm install


3. Start the Development Server
Launch the local Vite build asset watcher engine by typing:

# Terminal : npm run dev


4. Open the Web Browser
Once the server spins up, look at the terminal logs and click or browse to the provided local URL address interface 
# (usually http://localhost:5173).
